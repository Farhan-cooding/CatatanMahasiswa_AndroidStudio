# 📱 Aplikasi Catatan Mahasiswa (Jetpack Compose)

Aplikasi Android sederhana untuk mencatat aktivitas perkuliahan mahasiswa. Dibuat menggunakan **Android Studio** dan **Jetpack Compose (Material 3)**.

---

## 🛠️ Cara Menggunakan / Menjalankan Project Ini (Clone Project)

Bagi teman-teman yang ingin menjalankan project ini di Android Studio masing-masing, silakan ikuti langkah-langkah mudah berikut:

### Langkah 1: Salin Link Repository
1. Klik tombol hijau **`<> Code`** di bagian atas halaman ini.
2. Pada tab **HTTPS**, klik ikon **Copy** untuk menyalin link repository ini:
   `https://github.com/Farhan-cooding/CatatanMahasiswa_AndroidStudio.git`

### Langkah 2: Buka Android Studio
1. Buka aplikasi **Android Studio** di laptop/komputer kamu.
2. Di layar awal (*Welcome Screen*), klik tombol **Get from VCS** (atau dari menu atas: **File > New > Project from Version Control...**).

### Langkah 3: Clone Project
1. Pada kolom **URL**, tempel (*paste*) link repository yang sudah kamu salin tadi.
2. Tentukan folder penyimpanan pada kolom **Directory** (opsional).
3. Klik tombol **Clone** di pojok kanan bawah.

### Langkah 4: Tunggu Gradle Sync & Running
1. Tunggu beberapa saat sampai Android Studio selesai mendownload dan mengunduh dependensi (**Gradle Sync in progress...**). *Pastikan terhubung ke internet.*
2. Jika ada notifikasi *Trust Project*, pilih **Trust Project**.
3. Buka file `MainActivity.kt` di folder `app/src/main/java/com/example/catatanmahasiswa/`.
4. Pilih emulator/device kamu, lalu klik tombol **Play (Run)** 🟢 di bagian atas.
